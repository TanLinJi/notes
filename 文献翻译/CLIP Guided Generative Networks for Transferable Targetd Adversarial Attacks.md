# CLIP Guided Generative Networks for Transferable Targeted Adversarial Attacks

## Absrtact

​		**可迁移定向对抗攻击**旨在黑盒场景下误导模型输出攻击者指定的预测结果。近期的研究引入了**单目标生成式攻击**，即为每个目标类别训练一个生成器以生成高迁移性的扰动，这在处理多个类别时会导致巨大的计算开销。**多目标攻击**通过为多个类别仅训练一个**类条件生成器**来解决这一问题。然而，该生成器仅仅使用类别标签作为条件，未能利用目标类别丰富的语义信息。为此，我们设计了一种带有**交叉注意力模块**的 **CLIP 引导生成网络**（CGNC），通过将 **CLIP** 的文本知识整合到生成器中来增强多目标攻击。大量的实验表明，CGNC 相比于之前的多目标生成式攻击取得了显著的提升，例如，从 ResNet-152 到 DenseNet-121 的攻击成功率提高了 21.46%。此外，我们提出了一种**掩码微调机制**，以进一步加强我们的方法在攻击单个类别时的表现，该表现超越了现有的单目标方法。









## 1 Introduction

​		随着深度学习的快速发展，**深度神经网络**（DNNs）已广泛应用于许多安全关键领域，如自动驾驶、金融系统和点云建模。然而，DNNs 被证实容易受到**对抗攻击**的影响，这种攻击试图通过在原始输入中添加难以察觉的扰动来制作对抗样本以欺骗模型。根据攻击目标，对抗攻击可分为无目标攻击和定向攻击。无目标攻击试图欺骗 DNNs 预测出错误的标签，而定向攻击旨在触发模型输出攻击者期望的预测结果。

​		近期关于**对抗迁移性**的研究表明，针对白盒替代模型制作的对抗样本也能误导其他未知的黑盒模型。由于这种攻击不需要访问目标模型，它对 DNNs 的现实世界应用构成了严重的安全威胁，并激发了广泛的研究。尽管在无目标迁移攻击方面取得了显著的性能，但由于过度依赖白盒替代模型，这些方法在定向攻击方面的结果并不令人满意。现有的可迁移定向攻击研究可分为**特定实例攻击**和**通用实例攻击**。具体而言，特定实例攻击通过迭代执行梯度更新来制作针对特定自然样本的对抗扰动，但由于对白盒替代模型的过拟合，导致定向迁移性较低。相反，通用实例攻击基于数据分布而非特定实例来学习**通用扰动**或扰动生成器，从而缓解了数据特定的过拟合问题，并实现了更高的对抗迁移性。近期的研究进一步探索了**生成式攻击**以产生高迁移性的扰动，这可以分为单目标攻击和多目标攻击。

​	**单目标攻击**通过为目标类别训练扰动生成器表现出了令人印象深刻的性能。然而，它们需要为每个目标类别训练一个生成器，当攻击大量目标类别时，这会导致沉重的计算负担。因此，单目标攻击不适用于通常包含成百上千个目标类别的现实世界分类系统。为了解决这个问题，一些研究提出了**多目标攻击**，即为多目标类别训练单个条件生成模型。通过指定期望的标签作为条件输入，训练好的生成器可以高效地生成相应的定向对抗扰动。然而，这些方法仅仅采用**目标标签的类别索引或独热向量**（one-hot vectors）作为条件，因此只能完全依赖替代模型的分类信息作为目标类别的指导。因此，它们未能利用被攻击类别的丰富语义信息，导致黑盒欺骗率仅为中等水平。

​		在本文中，我们通过提出一种新颖的`带有交叉注意力模块的 CLIP 引导生成网络`（CGNC），建立在多目标攻击的研究路线之上，该网络利用了先进的视觉-语言模型 CLIP。具体来说，我们重新审视了现有研究中使用的条件生成器架构，并认为简单的类别条件（例如类别索引或手工设计的独热向量）限制了生成扰动的迁移性。受 CLIP 编码的文本嵌入在多模态学习中令人印象深刻的效果启发，我们`引入了目标类别的简明文本描述，将其编码为包含丰富信息的类别特定表示，`这有助于生成器学习目标类别的分布，并最终导致迁移性的根本性提升。为了更好地整合文本信息，我们通过添加已被证明在各种输入模态模型中有效的`交叉注意力层`，改进了条件输入机制。实验结果证实了我们的 CGNC 在捕获目标分布方面的能力。

​		此外，我们提出了一种掩码微调（MFT）技术，该技术使用期望类别的固定文本条件对训练好的条件生成器进行微调，以进一步提升攻击单个类别的效果。

​		通过上述所有努力，我们的方法实现了极高的效率和可扩展性。当存在数百个目标类别且单目标方法变得不切实际时，可以利用所提出的条件网络来实现显著优于先前多目标攻击的性能。相反，对于仅涉及少数目标类别的场景，所提出的 MFT 机制增强了 CGNC，使其性能优于现有的单目标方法，同时大幅降低了计算成本。

​		综上所述，我们的主要贡献如下：

- 我们提出了 CGNC，一种新颖的带有交叉注意力层的 CLIP 引导生成网络(CGNC)，它充分利用先进的 CLIP 模型提供的文本知识来增强多目标攻击。
- 我们引入了一种掩码微调机制，通过将 CGNC 适配到单个目标类别来提高单目标性能。
- 大量的实验表明，与之前最先进的攻击方法相比，我们提出的方法在各种设置下均实现了定向迁移性的显著提升。



## 5 Conclusion

​		在本文中，我们设计了一种新颖的生成网络 CGNC，它通过充分利用 CLIP 中丰富的先验知识作为关于目标类别的辅助语义知识，改进了多目标可迁移对抗攻击。为了更好地整合先验信息，我们引入了交叉注意力模块，并有效地以 CLIP 的文本嵌入作为生成器的条件。通过大量的实验，我们在多种场景下在多个黑盒目标模型上证明了所提出的 CGNC 的有效性。此外，我们提出了一种掩码微调技术，以进一步增强 CGNC 攻击单个类别的能力，该技术在效率和有效性方面均优于先前的单目标方法。我们希望所提出的方法能作为评估黑盒设置下模型鲁棒性的可靠工具，促进对 DNNs 脆弱性和鲁棒性的进一步研究。







## 术语

`Cross-attention modules`  交叉注意力模块。深度学习中的一种机制，允许模型在处理一种类型的数据（如图像特征）时，重点关注另一种类型数据（如文本特征）中的相关信息。



`One-hot Vectors`  一个长度等于总类别数（例如 1000）的向量。如果目标是第 3 个类别，向量就是 [0, 0, 1, 0, ..., 0]。

​		**问题**：这种向量是**稀疏**且**正交**的。这意味着任意两个不同类别的向量在空间上是完全垂直的（距离相等），无法体现出“猫”和“狗”比“猫”和“飞机”更相似这一点。本文指出，仅使用这种向量作为条件，导致生成器只能依赖替代模型的分类边界信息，而无法获得关于目标类别的具体语义指导
