# 3D adversarial attacks beyond point cloud

## Abstract

​		最近，**3D 深度学习**模型已被证明像它们的 2D 对应物一样，容易受到**对抗性攻击**的影响。大多数**最先进**（SOTA）的 3D 对抗性攻击是对 **3D 点云**执行扰动。为了在**物理场景**中复现这些攻击，生成的对抗性 3D 点云需要被重建为**网格**，这导致其对抗效果显著下降。在本文中，我们提出了一种名为 `Mesh Attack` 的强力 3D 对抗性攻击，通过直接对 **3D 物体**的网格执行扰动来解决这一问题。为了利用最有效的**基于梯度的攻击**，我们引入了一个**可微采样模块**，该模块将点云的梯度**反向传播**到网格。为了进一步确保对抗性网格样本没有**离群值**且可进行 **3D 打印**，我们采用了三种**网格损失**。广泛的实验表明，所提出的方案以显著优势优于 SOTA 3D 攻击。我们还在各种防御下实现了 SOTA 性能。我们的代码将在 <https://github.com/cuge1995/Mesh-Attack> 提供。

## 1 Introduction

​		**三维形状表示**是计算机视觉中最基础的主题之一。作为一种具有表现力的 3D 表示，点云可以直接从 3D 传感器（如**激光雷达**或 Kinect）输出，从而成为各种 3D 计算机视觉任务中的主要数据结构。网格是另一种实用的 3D 表示，广泛用于计算机图形学和**计算机辅助设计**（CAD）领域，但在计算机视觉领域受到的关注较少。借助 **3D 打印技术**，网格已成为连接**数字空间**和物理空间的桥梁。

​		为了更好地理解 3D 物体，一系列通过**深度神经网络**（DNNs）处理点云的工作已被提出，这进一步启发了下游任务（如 **3D 目标检测**）中的工作。随着 DNN 的发展，欺骗模型的**对抗样本**的威胁也越来越受到关注。对抗样本对人类来说是**不可察觉**的，但在测试阶段可以轻易欺骗 DNN，这在 2D 图像领域已被广泛研究。尽管已经提出了一系列工作，但 3D 对抗性攻击仍然相对探索不足，并存在若干问题。主要问题是现有工作几乎无法在物理上实现。它们大多通过添加或删除一些点或改变其坐标来对点云数据执行对抗性攻击。此类攻击仅限于数字世界中的**点云空间**，难以应用于真实环境，因为在真实环境中，点云要么由 3D 扫描仪生成，要么从重建的网格中采样。为了执行现实世界的对抗性攻击，**KNN 攻击**和 **$GeoA^{3}$ 攻击**进行了一些早期尝试。它们通过**点到网格重建算法**重建生成的对抗样本的网格，然后通过直接从网格表面采样获得点云。我们将这种攻击称为**伪物理场景攻击**。结果表明，$GeoA^{3}$ 攻击的对抗效果超过了 KNN 攻击，但从重建网格中采样的对抗性点云样本的性能与输入点云相比显著下降。在大多数情况下，**攻击成功率**从 $100\%$ 降至 $10\%$ 以下。此外，它们还通过使用 3D 扫描仪从 3D 打印物体中采样点云来执行真实的**物理场景攻击**，这些物体是从在伪物理场景中成功欺骗**点云分类器**的对抗性网格中随机选择的，以确保真实物理场景中的攻击成功率。在这种情况下，攻击性能进一步下降。这表明现实世界的点云攻击仍然是一项具有挑战性的任务。为了找出攻击性能下降的原因，我们在图 1 中展示了 KNN 攻击和 $GeoA^{3}$ 攻击的受扰动点云及其对应的网格。可视化表明，对抗性扰动虽然在点云空间中很小，但在重建的网格中导致了非常可观的“噪声”。这不仅导致了对抗信息的显著丢失，还使得重建网格非常难以进行 3D 打印，从而可能无法执行现实世界的攻击。

​		为此，在本文中，我们提出了 `Mesh Attack`，这是一种对网格数据而非点云执行扰动的 3D 对抗性攻击。我们旨在提高现实世界 3D 攻击的性能。然而，大多数 3D 物体识别方法都是基于点云的。因此，我们对 3D 点云分类器执行攻击。图 2 展示了我们的 Mesh Attack 与之前的点云攻击之间的主要区别。由于攻击直接应用于网格，因此避免了之前工作中重建网格中的“噪声”。为了将点云的梯度反向传播到网格，引入了一个`可微采样模块`。然而，直接向网格添加扰动会导致**自相交**和**飞离顶点**问题，从而引入大量离群值。这不仅会在 3D 打印过程中造成致命错误，而且很容易被**统计离群值移除**（SOR）方法防御，该方法会移除具有较大 **kNN 距离**的离群点。为了进一步确保对抗性网格样本没有离群值且可进行 3D 打印，采用了三种网格损失，即用于将网格顶点回归到其正确位置的倒角损失，以及使网格更平滑并避免网格自相交和飞离顶点问题的`拉普拉斯损失`和`边长损失`。通过将网格扰动限制在平滑的形状过渡上，消除了离群点。这不仅使我们的攻击在人类看来更自然，而且更难以被当前的点云防御算法防御。由于难以在真实的物理场景攻击中大规模比较 SOTA 3D 攻击，我们遵循了之前的设置，并在伪物理场景攻击中比较了 SOTA 3D 攻击。广泛的实验结果表明，我们的 Mesh Attack 以显著优势优于 SOTA 3D 攻击，这向现实世界的点云攻击迈出了重要一步。为了进一步验证我们 Mesh Attack 的有效性，我们执行了真实的物理场景攻击，结果表明，Mesh Attack 生成的大多数对抗性网格在扫描后都能成功攻击。此外，在伪物理场景中，针对不同受害者模型的各种防御下，我们提出的 Mesh Attack 的**对抗鲁棒性**以很大优势优于 SOTA 点云攻击算法。此外，由于对抗性网格样本是由 Mesh Attack 直接生成的，它们能够对 **MeshNet** 进行**黑盒攻击**，并实现了强大的攻击性能。据我们所知，Mesh Attack 是首次针对网格分类器的对抗性攻击。我们的 Mesh Attack 揭示了与网格相关的 3D 数据表示和分析的鲁棒性问题，我们希望这能为未来的现实世界 3D AI 研究和应用带来启发。

​		本文的主要贡献可以概括为：（1）我们提出了一种名为 Mesh Attack 的强力 3D 对抗性攻击方法，该方法可以直接生成对抗性网格样本。从网格样本中，可以采样出欺骗点云分类器的对抗性点云。（2）广泛的实验表明，我们的 Mesh Attack 在伪物理场景中以很大优势优于现有的点云攻击方法，并且难以被当前最先进的点云防御算法防御。（3）Mesh Attack 还被证明可以作为世界上首个针对网格分类器的 3D 对抗性攻击在黑盒设置下工作。

## 5 Conclusion and discussion

​		在本文中，我们提出了一种针对点云和网格的强力对抗性攻击，名为 Mesh Attack，它在攻击的每次迭代中更新网格顶点，并利用三种网格损失来正则化网格使其平滑。实验结果表明，我们的 Mesh Attack 以很大优势优于现有的点云攻击方法，并且难以被当前最先进的点云防御算法防御。我们还对**网格分类器**执行了黑盒攻击，结果很有希望。这为当前的对抗鲁棒性研究提出了一个新问题：我们真的需要在输入空间中执行对抗性攻击吗？随着 **NeRF** 在场景表示方面取得的巨大突破，我们认为这种场景表示中的攻击将是有前景的。此外，针对 Mesh Attack 的有效防御方法将是另一个关键且有前景的方向。另外，与图像领域不同，缺乏一种感知度量标准来像人类在 3D 领域那样衡量两个物体的相似程度（无论是点云还是网格），这将限制 3D 对抗性攻击和防御的研究。

​		然而，由于 Mesh Attack 的可微采样模块依赖于三角网格，因此 Mesh Attack 仅适用于**三角网格**。
