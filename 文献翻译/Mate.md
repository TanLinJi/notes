# MATE: Masked Autoencoders are Online 3D Test-Time Learners

### Abstract

​		我们的 MATE 是首个专为 **3D 数据** (3D data) 设计的 **测试时训练** (Test-Time-Training, TTT) 方法，它使针对 **点云分类** (point cloud classification) 训练的深度网络对测试数据中出现的 **分布偏移** (distribution shifts) 具有鲁棒性。与现有的来自 2D 图像领域的 TTT 方法类似，MATE 也利用测试数据进行 **自适应** (adaptation)。它的测试时目标是 **掩码自编码器** (Masked Autoencoder, MAE) 的目标：在将每个测试点云输入网络之前，先移除其大部分内容，并要求网络负责重建完整的点云。一旦网络得到更新，它就被用于对点云进行分类。我们在多个 3D 物体分类数据集 (3D object classification datasets) 上对 MATE 进行了测试，结果表明它显著提高了深度网络对 3D 点云中常见的几种 **损坏** (corruptions) 类型的鲁棒性。我们证明了 MATE 在自适应所需的点比例方面是非常高效的。在仅给定每个测试样本 $5\%$ 的 **标记** (tokens) 的情况下，它就能有效地进行自适应，这使其极其轻量化。我们的实验表明，MATE 通过在测试数据上进行 **稀疏自适应** (sparse adaptation) 也能获得具有竞争力的性能，这进一步降低了其 **计算开销** (computational overhead)，使其成为 **实时应用** (real-time applications) 的理想选择。

### 1 Introduction

​		近期的深度神经网络在分类 **3D 点云** (3D point clouds) 方面展现出了令人瞩目的性能。然而，只有当测试数据与训练数据源自相同的分布时，它们的成功才能得到保证。在现实世界的场景中，这一假设经常被打破。例如，由于传感器故障或环境因素，LiDAR 点云可能会受到损坏。在 [20, 24] 中已经表明，即使是看似微不足道的 **扰动** (perturbations)（如在点云中引入抖动或微量噪声），也能显著降低几种最先进的 **3D 物体识别** (3D object recognition) 架构的性能。这种 **鲁棒性** (robustness) 的缺乏限制了 3D 识别在众多应用中的效用，包括建筑业、地理测量、制造业和自动驾驶。能够影响 3D 数据的 **分布偏移** (distribution shifts) 在本质上是多种多样的，并且在测试时针对点云中可能观察到的所有偏移来训练网络可能是不切实际的。因此，我们需要以无监督的方式在测试时在线适应这些偏移。

​		**测试时训练** (Test-Time Training, TTT) 利用无标签的测试数据，以在线的方式使分类器适应测试时数据分布的变化。最近已经为 2D 图像领域提出了几种 TTT 方法。主要技术包括：使用定义在其预测熵上的目标函数在测试数据上对分类器进行正则化 [13, 28, 32]；更新批归一化层的统计数据以匹配测试数据的分布 [17]；以及使用自监督任务在测试数据上训练网络 [15,25]。然而，现有的 2D TTT 方法在简单生硬地应用于 3D 点云时会失败，这强调了对 3D 专属 TTT 方法的需求，而目前这种方法是不存在的。

​		在本文中，我们解决了针对 **3D 点云分类** (3D point cloud classification) 的测试时训练问题。我们提出了一种 3D 专属方法 MATE，它采用了自监督范式 [15, 25]，在该范式中，深度网络通过求解针对 **分布外** (OOD) 测试数据的自监督任务来进行自适应。我们的选择是由一项完美匹配我们适应 3D 网络目标的自监督任务的可用性所决定的。**掩码自编码器** (Masked autoencoder) 已被证明在预训练 3D 物体识别网络 [18] 以及使深度网络适应 2D 图像的损坏 [7] 方面非常有效。它移除点云的很大一部分，并要求网络在仅给定未被移除部分的情况下重建整个点云。我们使用此过程在每个用于自适应的测试样本上更新网络。图 1 提供了一个概述。

​		我们的主要贡献是将 TTT 扩展到 3D 点云领域，并表明简单地采用 2D 图像领域中广泛使用的 TTT 技术并不是 3D 数据的可行解决方案，突出了对 3D 专属方法的需求。为此，我们展示了掩码自编码在解决 3D 数据的在线测试时训练方面是多么合适且强大。我们在三个点云识别数据集上进行了广泛的评估。除了在在线自适应方面取得强大的性能提升外，我们还发现并强调了基于掩码自编码器进行 TTT 的几个有用特性。例如，即使掩蔽了点云中 95% 的 **标记** (tokens)，我们的 MATE 也能取得显著的性能提升。这种看似微小的细节可以带来重要的好处：在测试时，编码器只需要处理剩余 5% 的可见标记来使网络自适应，从而从根本上限制了自适应的计算开销。通过对测试数据进行稀疏自适应可以进一步降低 TTT 的开销，因为 MATE 仅通过对每 100 个 OOD 测试数据样本进行自适应，就能比未自适应的网络取得显著的性能提升。
