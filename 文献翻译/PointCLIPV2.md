# PointCLIP V2: Prompting CLIP and GPT for Powerful 3D Open-world Learning

### Abtract

​		**大规模预训练模型** (Large-scale pre-trained models) 在视觉和语言任务中都展示了极具前景的**开放世界** (Open-world) 性能 。然而，它们在 **三维点云** (3D point clouds) 上的迁移能力仍然有限，且仅局限于分类任务 。在本文中，我们首次将 **CLIP** 和 **GPT** 协作构建为一个统一的三维开放世界学习器，命名为 **PointCLIP V2**，它充分释放了两者在**零样本** (Zero-shot) 三维分类、分割和检测方面的潜力 。为了更好地将三维数据与预训练的语言知识对齐，PointCLIP V2 包含两个关键设计 。在视觉端，我们通过一个**形状投影模块** (Shape projection module) 来**提示** (Prompt) CLIP 生成更真实的深度图，从而缩小投影点云与自然图像之间的**领域间隙** (Domain gap) 。在文本端，我们提示 GPT 模型生成特定于三维的文本，作为 CLIP 文本编码器的输入 。在没有任何三维领域训练的情况下，我们的方法在三个用于零样本三维分类的数据集上，准确率分别大幅超越 PointCLIP 达 +42.90%、+40.44% 和 +28.75% 。在此基础上，V2 可以通过简单的方式扩展到**少样本** (Few-shot) 三维分类、零样本三维部分分割 和三维目标检测，展示了我们在统一三维开放世界学习方面的泛化能力 。代码可在 <https://github.com/yangyangyang127/PointCLIP_V2> 获取。

### 1 Introduction

​		近年来，空间传感器的进步引起了学术界和工业界的广泛关注 。为了有效地理解**三维点云** (3D point clouds) 这一三维数据的主要形式，许多相关任务被提出并取得了巨大进展，包括三维分类 、分割 、检测 以及**自监督学习** (Self-supervised learning) 。重要的是，由于开放世界环境的复杂性和多样性，收集到的三维数据通常包含大量“未见过”的物体，即从未被已部署的三维系统定义和训练过的物体 。鉴于人工数据标注的艰巨性，如何识别这些新类别的三维形状已成为一个热门问题，目前仍有待充分探索 。

​		最近，大规模预训练的视觉和语言模型，例如 **CLIP** 和 **GPT-3** ，已经获得了处理两种模态数据的强大能力 。然而，很少有工作关注它们在点云领域的应用，且现有工作仅探索了 CLIP 在三维分类任务上的可能性，未考虑其他三维开放世界任务 。**PointCLIP** 首次表明，在没有任何三维训练的情况下，CLIP 可以被适配用于**零样本点云分类** (Zero-shot point cloud classification) 。它将“未见过”的三维点云稀疏地投影到二维深度图中，并利用 CLIP 的图像-文本对齐来进行深度图识别 。然而，作为一项初步工作，PointCLIP 的性能远不能令人满意（如 `图1` 所示），无法投入实际使用 。更重要的是，PointCLIP 仅寻求预训练 CLIP 的支持，而没有考虑到强大的**大规模语言模型** (Large-scale language model, LLM) 。因此，我们提出了这样一个问题：我们能否恰当地统一 CLIP 和 LLM，以充分释放它们在统一三维开放世界理解中的潜力 ？

​		我们观察到，**PointCLIP** 主要受到有关 **2D-3D 领域间隙** (2D-3D domain gap) 的两个因素影响 。首先是 `稀疏投影` (Sparse Projection)：PointCLIP 简单地将三维点云投影到深度图上，形成带有深度值的稀疏分布点（如 `图 2` 所示）。尽管这种方式很简单，但这种散点风格的图像在外观和语义上都与现实世界的预训练图像截然不同，这严重干扰了 **CLIP** 的视觉编码器 。其次是 `朴素文本` (Naive Text)：PointCLIP 基本沿用了 CLIP 的二维文本输入模板，即“a photo of a [CLASS].”（一张 [类别] 的照片），仅附加了简单的三维相关词汇“a depth map”（一张深度图）。正如 `图 3` 所示，CLIP 提取的文本特征很难以高相似度分数聚焦于目标物体 。这种朴素的文本无法完全描述三维形状，并损害了预训练的语言-图像对齐 。

​		在本文中，我们整合了 CLIP 和 **GPT-3** [3] 模型的优势，提出了 **PointCLIP V2**。这是一个用于统一三维开放世界理解的强大框架，涵盖了**零样本/少样本** (Zero-shot/Few-shot) 三维分类、零样本**部分分割** (Part segmentation) 以及零样本三维**目标检测** (Object detection) 。在不“看到”任何三维训练数据的情况下，V2 可以将点云投影为真实的二维图像，并将其与具备三维感知能力的文本对齐，从而充分释放 CLIP 在三维领域的预训练知识 。

​		首先，我们提出**利用真实投影来提示 CLIP** (Prompt CLIP with Realistic Projection)，从三维点云中生成 CLIP 更偏好的图像 。具体而言，我们将不规则的点云转换为基于网格的**体素** (Voxels)，然后在上方应用非参数化的三维局部滤波 。通过这种方式，投影的三维形状由更密集的点和更平滑的深度值组成 。如 `图 2` 所示，我们生成的图像在视觉上更接近现实世界的图像，能够极大地释放 CLIP 预训练视觉编码器的表达能力 。

​		其次，我们提出**利用三维指令来提示 GPT** (Prompt GPT with 3D Command)，生成具有丰富三维语义的文本作为 CLIP 文本编码器的输入 。通过向 GPT-3 输入启发式的三维导向指令（例如：“Give a caption of a table depth map:”（给桌子的深度图写一段说明）），我们利用其语言生成知识获取一系列特定于三维的文本，例如：“A height map of a table with a top and several legs.”（一张带有桌面和几条腿的桌子高度图） 。我们定制了一组语言指令来提示 GPT-3 产生多样化的、包含三维形状信息的文本 。如 `图 3` 所示，PointCLIP V2 的文本特征对投影图展现出更强的匹配属性，极大地增强了 CLIP 对三维点云的图像-文本对齐 。

​		凭借我们的提示方案，PointCLIP V2 在零样本三维分类中表现出优异的性能，在 ModelNet10 [53]、ModelNet40 [53] 和 ScanObjectNN [44] 数据集上，其准确率分别超过 PointCLIP 达 +42.90%、+40.44% 和 +28.75% 。此外，通过少量的修改，我们的方法可以适配更多非平凡的三维开放世界任务，例如用于三维少样本分类的**可学习三维平滑** (Learnable 3D smoothing)、用于零样本地图分割的**反向投影头** (Back-projection head)，以及用于零样本检测的**三维区域提议网络** (3D region proposal network) 。这充分表明了 V2 在通用三维开放世界理解方面的强大能力 。

​		我们的贡献总结如下：

- 我们提出了 **PointCLIP V2**，这是一种强大的**跨模态学习器** (Cross-modal learner)，它统一了 **CLIP** 和 **GPT-3**，旨在将预训练的视觉-语言知识迁移到三维领域 。

- 我们引入了`真实投影` (Realistic projection) 来提示 CLIP，并引入了`三维导向指令` (3D-oriented command) 来提示 GPT-3，从而有效地缓解了二维、三维与语言之间的**领域间隙** (Domain gap) 。

- 作为统一三维**开放世界学习** (Open-world learning) 的首项工作，我们的 PointCLIP V2 可以进一步扩展到**零样本部分分割** (Zero-shot part segmentation) 和**三维目标检测** (3D object detection) 任务中 。

### 2 Related Works

​		`三维开放世界学习` (3D Open-world Learning) 传统的 **三维开放世界学习** 方法仍然需要三维训练数据作为预训练阶段 。Cheraghian 等人的一系列工作通过在隐空间中最大化类间散度，在“已见过” (seen) 的三维类别上训练**零样本分类器** (Zero-shot classifiers)，然后在“未见过” (unseen) 的类别上进行测试 。一些近期的工作 [30, 24, 32, 27] 还研究了针对更复杂三维场景的开放世界**语义分割** (Semantic segmentation) 和三维**目标检测** (3D object detection) 。受基于 CLIP 的适配方法 [60, 13, 23] 的启发，PointCLIP [62] 在没有任何三维数据集训练的情况下实现了零样本点云识别 。通过迁移预训练的 **CLIP** 模型 [37]，二维知识可以被有效地利用于识别三维数据 。CLIP2Point [19] 通过额外的大规模三维预训练，进一步提升了 CLIP 在点云上的适配性能 。在本文中，我们提出了 **PointCLIP V2**，并遵循 PointCLIP 的开放世界设置，如 `图 4` 所示，这种设置比以往的方法更具挑战性 。我们不需要任何“已见过”的三维训练，并且首次同时进行零样本三维**部分分割** (Part segmentation) 和目标检测，实现了统一的三维开放世界理解 。

​		`点云投影` (Projection for Point Clouds) 与基于点的方法 并行，基于投影的点云分析旨在通过将点云投影为二维图像 ，从而在三维领域利用丰富的二维网络。其中，**PointCLIP** 遵循 **SimpleView** 采用**透视变换** (Perspective transformation) 作为三维到二维的投影方式，这实现了高效率但分类准确率有限 。在三维开放世界设置下，我们动力开发更高效且更真实的投影方法，以在点云数据上**提示** (Prompting) **CLIP** 。在 `表 1` 中，我们将我们的方法与现有的先进投影方法在延迟和准确率方面进行了比较 。为了公平比较，我们在 V2 的流水线下实现了所有之前的工作，即采用我们的 **GPT 提示** (GPT prompting) 方法以充分展示其有效性 。如表所示，我们的**真实投影** (Realistic projection) 展现出比其他方法更快的推理速度，并获得了比 PointCLIP 更高的零样本性能 。

​		`视觉提示学习` (Prompt Learning in Vision) **提示工程** (Prompt engineering) 最初起源于自然语言处理，通过生成被称为“提示”的文本模板，来缩小预训练前置任务与下游场景之间的**领域间隙** (Domain gap) 。受此启发，**CoOp** [69] 首次将**可学习提示** (Learnable prompting) 引入二维视觉-语言分类中，随后的 **CoCoOp** [68] 将其扩展到二维领域泛化任务 。**CuPL** [34] 和 **CaFo** [63] 利用 **GPT-3** [3] 来增强 **CLIP** 在各种二维数据集上的下游性能 。从另一个角度来看，**视觉提示** (Visual prompting) 方法建议在输入图像中附加可学习的视觉像素 [21, 2, 5, 12] 或**嵌入** (Embeddings) [21, 16, 64]，从而在不进行下游微调的情况下改进预训练的视觉骨干网络 。在本文中，我们寻求通过`真实投影`来提示 CLIP 的视觉编码器，并通过 GPT-3 提示其文本编码器，以提高其零样本预测能力 。

​		`GPT-3 模型` (GPT-3 Model) **生成式预训练 Transformer** (GPT) 模型 [38, 39, 3] 在处理自然语言方面取得了持续的进步 。其中，与其前身 [38, 39, 26, 56, 40] 相比，GPT-3 在语言理解和生成方面都表现出了卓越的能力 。GPT-3 是一个拥有 1750 亿个可训练参数的大规模**自回归语言模型** (Autoregressive language model) 。尽管尚未开源，但一些工作已经探索了将其应用于下游任务，例如用于视觉问答的 **PICa** [57]、用于二维零样本识别的 **CuPL** [34] 以及用于二维少样本学习的 **CaFo** [63] 。在本文工作中，我们首次通过**三维相关指令**提示 GPT-3 [3]，以助力开放世界三维任务 。



### Conclusion

我们提出了 **PointCLIP V2**，这是一种强大且统一的**三维开放世界学习器** (3D open-world learner)，它以显著的优势超越了现有的 PointCLIP 。我们建议通过一个`真实投影模块` (Realistic projection module) 来提示 CLIP，以便从三维数据中生成高质量的深度图，并提示 GPT-3 模型生成特定于三维的描述 。通过提示机制，视觉和语言表示实现了更好的对齐 。除了分类任务外，V2 还可以泛化到各种具有挑战性的任务并取得令人期待的性能，包括三维**少样本分类** (Few-shot classification)、三维**零样本部分分割** (Zero-shot part segmentation) 和**目标检测** (Object detection) 。对于未来的工作，我们将进一步探索如何使 CLIP 适配更广泛的开放世界应用，例如室外三维检测和**视觉定位** (Visual grounding) 。
