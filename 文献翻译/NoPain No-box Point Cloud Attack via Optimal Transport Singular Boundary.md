# NoPain No-box Point Cloud Attack via Optimal Transport Singular Boundary

## Abstract

​		**对抗攻击**利用了深度模型对**对抗样本**的脆弱性 。现有的点云攻击者通常是针对特定模型定制的，它们在**白盒**或**黑盒**设置下，基于**梯度**对**扰动**进行**迭代优化** 。尽管它们表现出良好的攻击性能，但由于对**替代模型**特定参数的**过拟合**，它们往往难以生成**可迁移的**对抗样本 。为了克服这一问题，我们将关注点转移到**数据分布**本身，并引入了一种名为 `NoPain` 的新颖方法，该方法利用**最优传输**（OT）来识别**数据流形**固有的**奇异边界**，以实现跨网络的点云攻击 。具体来，我们首先计算从噪声到目标**特征空间**的**OT映射**，然后通过定位**不可微**位置来识别**奇异边界** 。最后，我们沿着**奇异边界**进行采样，以生成对抗点云 。一旦确定了**奇异边界**，NoPain 就能高效地生成对抗样本，而无需**迭代更新**或来自**替代分类器**的指导 。大量的实验表明，所提出的**端到端**方法在**迁移性**和效率方面均优于**基线方法**，同时即使对抗**防御策略**也保持了显著优势 。代码和模型可在 <https://github.com/cognaclee/nopain> 获取 。

## 1 Introduction

​		近期的研究广泛审查了**深度神经网络**（DNNs）的**对抗脆弱性** [2, 7, 14, 17, 39, 41, 50]，证明了即使是对输入数据的**微小扰动**也能导致先进的 DNN 模型做出**错误预测** 。这种脆弱性对**安全关键系统**构成了重大威胁，并激发了关于**对抗攻击**的研究，以提高模型的**鲁棒性** 。

​		鉴于**3D DNNs**在**自动驾驶**和**机器人导航**等安全敏感应用中的关键作用，各种**点云攻击方法** [12, 13, 19, 22, 32, 34, 35, 45, 49, 51–53, 62, 64] 被开发出来，旨在从不同角度**扰动**数据，有效地揭示了当前**点云分类器**的脆弱性 。这些方法大多数是**白盒攻击** [12, 13, 23, 34, 36, 45, 46, 49, 51, 53, 58, 64]，需要访问目标模型的**结构**、**权重**和**梯度** 。然而，当在不同的网络上进行测试时，它们的有效性显著降低，表明**攻击迁移性**较低 。

​		旨在增强**黑盒**设置下**攻击迁移性**的当代进展 [9, 19, 21, 22, 32, 33, 52, 60, 62] 可以分为两个主要类别：**基于迁移的攻击**和**基于边界的攻击** 。**基于迁移的方法**通常利用**自编码器**或**替代模型**的部分参数来增强攻击的迁移性 。**基于边界的攻击**旨在通过在**决策边界**处生成**扰动**来提高迁移性，从而改变预测结果 。虽然这些技术增强了迁移性，但它们需要访问部分模型参数或多次查询**代理模型**，以便对**对抗样本**进行**迭代优化** 。这种对模型特定策略的依赖引入了**过拟合**的风险，最终限制了它们的迁移性 。

​		一些研究人员已经通过关注**全局分布对齐**来探讨攻击方法 。作为一种强大的**分布对齐**工具，**最优传输**（OT）已成功应用于图像领域的**可迁移攻击** [20, 25, 31] 。Han 等人 [20] 利用 OT 来对齐图像和文本分布，增强了**图像-语言模型**中攻击的迁移性 。Labarbarie 等人 [25] 通过将**替代分类器编码器**生成的**对抗图像**的特征与目标图像的特征进行对齐，实现了**补丁对抗攻击** 。这提出了关键问题：**替代模型**是必须的吗？**对抗样本**必须通过优化获得吗 ？作为回应，本文探索了一种**无盒**（免分类器）的**端到端点云攻击** 。

## 2 Related Work

​		`点云上的白盒攻击。`现有的点云攻击工作大致可分为**白盒攻击**和**黑盒攻击** 。近年来，大多数**白盒攻击**工作采用**基于点的攻击** [34, 49, 53, 64] 。Liu 等人 [34] 将**基于梯度的**对抗攻击 **FGSM** [17] 策略扩展到了点云 。3D-Adv [58] 在点云攻击中引入了 **C&W 攻击框架** [7]，通过移动**点坐标**和添加额外的点来生成对抗样本 。Tsai 等人 [53] 改进了 **C&W 攻击框架**，引入了一个 **KNN 正则化项**来抑制**离群点**并使点云表面紧凑 。GeoA³ [55] 使用了一种组合的**几何感知目标**来维持**局部曲率一致性**和均匀的表面 。Zheng 等人 [65] 提出，删除少量具有高**显著性**的点可以有效地导致分类错误 。除了上述**基于点的**方法外，一些研究还探索了**基于形状的攻击** 。Liu 等人 [35] 通过向对象添加新特征引入了**基于形状的攻击** 。Zhang 等人 [61] 和 Miao 等人 [13] 提出直接攻击**网格**以生成更平滑的结果 。Tang 等人 [51] 提出对**自编码器**中的**隐变量**进行对抗性拉伸，这可以被解码为平滑的**对抗点云** 。HiT-ADV [36] 是一种**基于形状的攻击**，它首先基于**显著性**和**不可感知性分数**搜索攻击区域，然后使用**高斯核**在每个攻击区域添加**形变扰动** 。此外，一些工作 [13, 23, 46, 51] 在**特征空间**中攻击点云以实现不可感知的攻击 。虽然这些方法消除了**离群点**并确保了平滑度，但它们仍然需要对每个点云进行**优化**，导致了高昂的时间成本 。为此，**通用攻击** [12, 45] 被提出来计算具有特定模式的点云的**通用扰动** 。

​		`点云上的黑盒攻击。`**黑盒攻击**可以进一步分类为**基于迁移的** [6, 19, 22, 32, 33, 60, 62] 和**基于边界的黑盒攻击** [9, 21, 52] 。对于点云，大多数工作集中在**基于迁移的黑盒攻击**上 。AdvPC [19] 利用**点云自编码器**来增强**对抗点云**的**迁移性**，而 AOF [32] 针对 3D 点云的**低频分量**来破坏**通用特征** 。SI-Adv [22] 将点投影到**切平面**上并引入**扰动**，以创建**形状不变**的点云 。Eidos [60] 是一种**基于迁移的攻击**，它允许在一个分类器上训练的**对抗样本**被迁移到另一个分类器上 。3DHacker [52] 仅使用**黑盒硬标签**来生成**对抗样本** 。PF-Attack [21] 和 ANF [9] 通过**决策边界**附近的**对抗噪声分解**来优化**扰动**及其子分量，从而减少了对**替代模型**的依赖并增强了**迁移性** 。SS-attack [62] 对输入点云应用随机**缩放**或**剪切**，以防止对**白盒模型**的**过拟合**，从而提高了**攻击迁移性** 。虽然这些方法增强了模型的**迁移性**，但它们仍然依赖于基于标签的**对抗样本**的**迭代生成** 。

​		`无盒攻击。`**无盒**方法是一种**免分类器**的攻击策略，它既不需要访问**分类器细节**，也不需要进行**模型查询**。迄今为止，只有少数研究针对图像或**骨架**解决了这一具有挑战性的设置 。Li 等人 利用**自编码模型**设计了一种用于**无盒图像攻击**的**对抗损失**。Sun 等人 使用训练集的一个小子集来训练一个**辅助模型**，利用该模型生成**对抗样本**并攻击目标模型。Lu 等人 定义了一种**对抗损失**，以最大化每个对抗样本与**正样本**的**相异性**，同时最小化其与**负样本**的相似性，用于**骨架攻击**。Zhang 等人 结合了干净图像的**低频**部分和**纹理图像**的**高频**部分来制作**对抗样本**。Mou 等人  开发了一种**基于决策的**攻击策略，该策略生成**通用对抗扰动**和一组**纹理对抗实例**。

# 术语

`Surrogate Model`  替代模型，在无法获取目标模型的参数时，攻击者自己训练的一个模型，用来模拟目标模型的行为。



`Optimal Transport, OT`  最优传输，OT 理论最初由法国数学家蒙日（Monge）在 18 世纪提出。

- **场景**：假设你有一堆形状不规则的**土堆**（源分布，Source），你需要把这堆土搬运去填满一个形状不规则的**土坑**（目标分布，Target）。土的体积和坑的容积是相等的。
- **代价**：搬运每一铲土都需要消耗体力，消耗量 = 土的重量 $\times$ 搬运距离。
- **目标**：设计一个搬运方案（哪个位置的土填到坑里的哪个位置），使得总的**体力消耗最小**。

这个“总消耗最小”的搬运方案，就是**最优传输映射**（Optimal Transport Map）。在深度学习中，我们不搬土，而是搬运**概率分布**。

- **源 ($\mu$)**：通常是一个简单的分布，比如**高斯噪声**（Gaussian Noise）。想象一团没有形状的、均匀分布的气体。
- **目标 ($\nu$)**：数据的真实特征分布（Data Manifold）。比如点云数据在特征空间中聚集成的一簇簇形状（椅子簇、飞机簇等）。
- **OT 映射**：找到一个函数 $T(x)$，把噪声空间中的点 $x$ 映射到特征空间中的点 $y$，不仅要让分布形状吻合，还要让移动的总“距离”最短。

这篇论文使用的是 **半离散最优传输 (Semi-Discrete Optimal Transport, SDOT)**，这是理解文章创新点 **"Singular Boundary"** 的关键。

- **半离散 (Semi-Discrete)**：

  - 文章的**输入（噪声）**是连续的（Continuous Noise Space）。
  - 文章的**目标（特征）**是离散的（Discrete Data Points），即训练集中一个个具体的点云特征。

- **为什么能找到攻击边界？（重要理解）** 想象一下下雨（连续的雨滴，即噪声）落在地面上几十个不同的**漏斗**（离散的目标特征，代表不同的点云类别）里。

  - **OT 映射**决定了每一滴雨水最终会流进哪个漏斗。
  - **普通区域**：在大部分区域，雨水很顺畅地流进最近的漏斗（映射是平滑的、可微的）。
  - **奇异边界 (Singular Boundary)**：这就好比两个漏斗之间的**“分水岭”**或**“脊线”**。雨水落在这个脊线上时，它往左流是漏斗 A，往右流是漏斗 B。

  **在数学上，这个“脊线”位置的映射是不可微的（Non-differentiable）。**

**总结对论文的意义：** 作者不需要训练一个模型来告诉他决策边界在哪里。通过计算 OT，通过数学方法直接就能找到这些天然的“分水岭”（奇异边界）。**攻击**的本质，就是故意生成落在这些“分水岭”上的点，让模型不知道该把它分给 A 还是分给 B，从而导致分类错误。



`Singular Boundary` 奇异边界，在最优传输（OT）理论中，传输映射发生不连续或不可微的区域。在几何上，这通常对应于不同数据簇（Cluster）的分界线。

​		*通俗理解*：类似于地图上的“分水岭”。站在分水岭（奇异边界）上，往左一步水流向太平洋，往右一步流向大西洋。在这个位置生成的样本，极其容易让模型产生混淆。



`Data Manifold`  数据流形，在高维空间中，数据点通常不是均匀分布的，而是聚集在某个低维的几何结构附近，这个低维结构就称为流形。

​		*通俗理解*：想象一张卷曲的纸（2D流形）漂浮在三维空间中。虽然纸上的点有 $(x, y, z)$ 三个坐标，但它们本质上只分布在那张纸面上。点云数据虽然维度很高，但有效的形状特征通常分布在一个特定的“形状空间”里。



`White-box Attack`  白盒攻击，一种攻击假设，攻击者拥有对目标模型的完全访问权限，包括网络架构、参数权重、训练数据以及梯度信息。



`Transfer-based Attack` 基于迁移的攻击，一种黑盒攻击策略。攻击者训练一个可以访问的“替代模型”（替身），在这个替身模型上生成对抗样本，并期望这些样本能“迁移”去攻击未知的目标模型。

​		*通俗理解*：就像你要去踢馆（攻击目标模型）但不知道对手的招数，于是你找了个和对手师出同门的师弟（替代模型）来练手。如果你练出的绝招能打败师弟，你希望它也能打败那个对手。



`Boundary-based Attack`  基于边界的攻击，一种黑盒攻击策略。通过不断试探模型的输出（通常是硬标签，即只知道是“猫”还是“狗”，不知道概率），来寻找模型分类发生变化的临界点（决策边界），并在那里制造扰动。

​		*通俗理解*：类似于在悬崖边试探。你闭着眼睛（不知道模型内部），一步步往悬崖边挪，直到正好站在掉下去和掉不下去的边缘（边界），然后轻轻推一把。



`Distribution Alignment` 分布对齐，一种统计学方法，旨在减小两个不同数据集（例如源域和目标域，或者图像和文本）在特征空间分布上的差异，使它们看起来更相似。

​		*通俗理解*：把两堆形状不同的沙子（两个分布）推推在在，让它们堆成的形状尽可能重合。



`Adversarial Patch Attack` 补丁对抗攻击，攻击者不是在整个图像或物体上添加肉眼看不见的微小噪声，而是生成一个**局部的**、**可见的**、且图案非常明显的“补丁”（通常是一个小方块或圆形区域）。将这个“补丁”粘贴在输入数据（如图片）的任意位置，就能让模型立刻识别错误。

| **特性** | **普通对抗攻击 (Global Perturbation)** | **补丁对抗攻击 (Patch Attack)**                      |
| -------- | -------------------------------------- | ---------------------------------------------------- |
| **范围** | 修改整个图像的所有像素/所有点          | **仅修改一小块区域**                                 |
| **强度** | 极其微小，肉眼几乎无法察觉             | **非常剧烈**，肉眼明显可见（像个贴纸）               |
| **目标** | 让模型在不知不觉中犯错                 | **鲁棒性**，即使在物理世界打印出来贴在物体上也能生效 |

最著名的例子是谷歌研究人员做出的“**烤面包机贴纸**”。在桌子上放着一根香蕉，正常情况下AI识别为香蕉，但是攻击者在香蕉旁边放置了一张打印出来的花花绿绿的圆形贴纸(这就是对抗补丁)，导致AI忽略了香蕉，将这张图说成是烤面包机。



`KNN Regularization` KNN正则化，在损失函数中加入一项，限制每个点必须与其最近邻居（K-Nearest Neighbors）保持一定的距离关系。

​		*通俗理解*：防止“离群点”产生。就像要求大家排队时不能有人突然站得离队伍太远，保证生成的点云看起来还是一个紧凑的物体，而不是周围散落着乱七八糟的噪点。



`Hard Labels`  硬标签，模型输出的最终分类结果，仅包含类别信息（例如：“这是一只猫”），而不包含每个类别的预测概率。

​		*通俗理解*：像是一个只告诉你“对”或“错”的老师，而不告诉你你离正确答案差了多少分。攻击者只能根据这个简单的反馈来瞎猜如何改进攻击，难度比知道具体分数（软标签）要大得多。



`Low-frequency Components`  低频分量，在信号处理（这里指点云的几何特征）中，代表数据整体轮廓、大尺度形状的特征。

​		*通俗理解*：如果你看一张桌子的照片，桌子的整体长方形轮廓就是“低频”信息，而桌子表面的木纹纹理就是“高频”信息。AOF 攻击通过破坏这些“大轮廓”特征，让模型更容易识别错。
