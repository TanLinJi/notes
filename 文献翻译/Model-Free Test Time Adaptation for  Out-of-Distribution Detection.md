# Model-Free Test Time Adaptation for  Out-of-Distribution Detection

### Abstract

​		分布外 (Out-of-distribution, OOD)检测对于机器学习(ML)模型的可靠性至关重要。现有的多数OOD检测方法从给定的分布内 (in-distribution)数据集中学习一个固定的决策标准，并将其普遍应用于决定数据点是否为OOD。`最近的研究 Fang et al. (2022) 表明，如果仅给定分布内数据，在没有额外假设的情况下，不可能可靠地检测出OOD数据`。受此理论结果以及近期对测试时自适应 (test-time adaptation)方法的探索的启发，我们提出了一种用于`分布外检测的非参数测试时自适应框架 (AdaODD)`。与传统方法不同，AdaODD在测试期间利用在线测试样本进行模型自适应，从而增强了对不断变化的数据分布的适应性。该框架将被检测出的OOD实例纳入决策过程中，降低了假阳性率 (false positive rates)，尤其是在ID和OOD分布严重重叠的情况下。我们通过在多个OOD检测基准上的全面实验证明了AdaODD的有效性，大量的实证研究表明，与最先进的方法相比，AdaODD显著提升了OOD检测的性能。具体而言，与高级方法相比，AdaODD在CIFAR-10基准上将假阳性率 (FPR95) 降低了23.23%，在ImageNet-1 k基准上降低了38%。最后，我们从理论上验证了AdaODD的有效性。



### 1 Introduction

​		当训练和测试数据来自不同的分布时，传统的机器学习模型通常会表现出次优的性能。这一弱点阻碍了机器学习系统在现实世界中的部署，特别是在自动驾驶 [2] 和生物特征身份验证 [3] 等安全关键型应用中。为了减轻分布外 (Out-of-Distribution, OOD)数据的风险，OOD检测问题已被广泛研究 [4], [5], [6]，该问题需要一个异常值检测器来判断输入是分布内 (In-Distribution, ID)还是OOD。对于ID输入，系统将预测其真实的类别，而OOD输入则会被拒绝并且不被预测。人们已经开发了各种方法来提高OOD检测的性能，包括使用分类置信度或熵 [4], [7]、对ID密度进行建模 [8], [9]、计算特征距离 [5], [10]，以及在训练期间暴露于OOD样本 [11]。

​		尽管取得了令人鼓舞的进展，但所实现的OOD检测性能仍然有限，特别是在大规模数据集上 。例如，对于包含1,280,000张带标签图像的大规模ImageNet任务 [12]，即使使用最先进的OOD检测方法，OOD检测的假阳性率也仅为53.97%，也就是说，超过一半的OOD样本未能被成功检测出 。最近为OOD检测提出的不可能性定理 (impossibility theorem) [1] 进一步凸显了OOD检测的挑战，即在不做出强假设的情况下，如果仅能访问ID数据点，是不可能可靠地检测出OOD数据的 。  

​		正如文献 [1] 中的不可能性定理所示，OOD检测的根本挑战源于没有任何可用的OOD数据点。因此，模型从ID数据集中学习到了一个固定的决策标准，并将其普遍应用，而忽略了OOD的分布情况。为了进一步凸显这一局限性，我们在图 1 中构建了一个说明性示例，其中ID数据点是从正态分布$$N(0, 1)$$中采样的。遵循典型的OOD检测方法（例如，[13]），我们将区分ID/OOD样本的阈值设置为 1.96，因为它对ID分布达到了 95% 的置信度。当OOD分布远离ID分布时，这种方法效果很好。但是，如图 1 所示，当两个分布显著重叠时，这种方法会对OOD样本产生高得多的假阳性率（接近 50%），这意味着有必要基于测试样本来调整决策标准。一种可能的解决方案是，根据已经被检测为OOD样本的测试样例来动态调整阈值。特别是，对于图 1 中展示的示例，利用检测到的OOD样本，我们能够降低阈值，从而大幅降低OOD检测的假阳性率。（详细的实验设置在 C 节中描述）。

​		受该示例的启发，我们提出在一个完全的测试时自适应设置 [14] 下研究OOD检测，该设置假设测试样本来自在线数据流，并可用于调整模型。这不同于传统的OOD检测研究，在后者中，被检测到的OOD样本无法得到充分利用。测试时自适应允许我们使用在线测试样本，这更符合现实场景，在这些场景中，预训练模型被期望在做出预测之前，于测试期间去适应无标签数据。

​		直观地说，`通过使用被标记为OOD的测试样本，我们可以近似估计OOD分布并调整决策标准，以提高OOD检测的准确率`。然而，现有的TTA方法大多为分类任务而设计，并利用伪标签 (Pseudo-label) 以在线方式重新训练模型 [14], [15], [16], [17] 。将这些方法应用于OOD检测任务绝非易事，因为模型仅使用ID实例进行训练，且ID与OOD的标签空间是不相交的 。为此，我们提出了一种简单而有效的方法，即用于`分布外检测的非参数 (Non-parametric) 测试时自适应框架`（简称AdaODD），`从而最大限度地利用由现有决策标准赋予伪标签的在线测试样本`。具体而言，我们构建了一个特征记忆库 (Feature Memory Bank)，以收纳训练阶段生成的所有特征向量 。对于一个测试样本，我们基于其在记忆库中的 $k$ 近邻 (k-nearest neighbors) 计算其得分，并在该得分超过`给定阈值`时将其标记为OOD 。任何被标记为OOD的测试样本都会被并入记忆库中，用于未来的得分计算 。总而言之，我们做出了三项贡献 ：

1) 我们通过存储测试实例的特征库，探索了一种执行TTA的非参数范式 。所提出的AdaODD可以与任何用于OOD检测的后端模型相结合。我们证明，将在线检测出的OOD实例纳入决策过程可以降低假阳性率，特别是当分布内/外存在大量重叠时 。我们从最大似然估计器的视角论证了AdaODD设计的合理性 。

2) 我们在多个OOD检测基准上进行了全面的实验 。结果表明，与最先进的基线方法相比，AdaODD能够大幅降低假阳性率，例如，AdaODD在ImageNet-1 k基准上将FPR降低了38% 。

3) 我们对AdaODD的各个组件进行了彻底的消融研究 (Ablation Studies) 。这些结果阐明了我们在考虑不同规模的数据集时应如何选择超参数 。  

### 2 Methods

​		`符号说明` 给定一个输入空间 $\mathcal{X}$、表示空间 $\mathcal{Z}$ 以及标签空间 $\mathcal{Y}=\{1,2,...,c\}$，我们拥有一个抽取自分布 $\mathcal{D}^{in}$ 的分布内 (ID) 数据集 $D_{in}=\{(x_{i},y_{i})\}_{i=1}^{N}$ 。我们有一个不同于 $\mathcal{D}^{in}$ 的 OOD 分布 $\mathcal{D}^{out}$ 。我们还有一个特征编码器 $h_{\theta}:\mathcal{X}\rightarrow\mathcal{Z}$ 和一个分类器 $f:\mathcal{Z}\rightarrow\mathbb{R}^{c}$，其中 $h_{\theta}$ 和 $f$ 通常由深度神经网络进行参数化 。  

​		`测试时分布外 (OOD) 检测` 给定采样自 ID 分布 $\mathcal{D}^{in}$ 的数据 $D_{in}$，我们训练一个神经网络 $h_{\theta}\circ f$ 。`我们的目标是构建一个得分函数 S(x)，该函数为 ID 样本分配较高的分数，而为 OOD 样本分配较低的分数` 。形式上，给定一个阈值 $\lambda$ 和输入 $x$，由指示函数 $I\{S(x)\ge\lambda\}$ 来决定 $x$ 是否来自 $\mathcal{D}^{in}$，否则，$x$ 会被分类为 OOD 样本 。在本文中，与以往的 OOD 检测研究（例如 [6]）类似，我们假设来自 $\mathcal{D}^{out}$ 样本的标签与 $\mathcal{D}^{in}$ 的标签互不重叠，这通常被称为**标签偏移** (Label Shift) 。与现有的研究 [6] 不同的是，在推理阶段，我们不仅提出去检测 OOD 实例，还要利用这些示例来提升检测能力 。我们在线上可获取的附录 A 中讨论了所有相关工作 。(这个和上一篇多缓存增强的有相似之处，原来丢弃负缓存，现在保留负缓存并用于更好的判断。原来丢掉OOD,这里利用OOD来支持更好的判断)

#### A. Motivation of Test-Time Adaptation

​		正如引言中所讨论的，在没有 $\mathcal{D}^{out}$ 的情况下，一个独立于测试样本的固定决策阈值（即 $x = 1.96$）可能效果不佳，特别是当 ID 和 OOD 分布显著重叠时 。另一方面，利用我们的检测算法标记为 OOD 的测试样本，我们可以获得对 $\mathcal{D}^{out}$ 的估计，并将决策阈值降低到 $x = 1.35$ 。这将使 91% 的 ID 样本和 90% 的 OOD 样本被正确分类，在仅牺牲少量 ID 样本分类准确率（4%）的情况下，使 OOD 检测实现了显著的提升（40%）。为了进一步定量研究 OOD 样本对 OOD 检测性能的影响，在图 1(c) 中，我们包含了使用不同数量的、来自 $\mathcal{D}^{out} = \mathcal{N}(2, 1/2)$ 的 OOD 样本时的 OOD 检测性能（有关详细的实验设置，请参阅在线提供的附录 C）。结果表明，即使只有少量的 OOD 样本，与仅仅依赖 ID 样本的检测算法相比，我们的算法也能大幅降低 FPR 。

#### B. Non-Parametric Test Time Adaptation for Out-of-Distribution Detection

​		在这里，我们描述 AdaODD 并讨论其与现有 OOD 检测器相比的主要优点。

​		**K-近邻 (K-Nearest Neighbors, KNN)** [13] 是一种基于距离的 OOD 检测方法，它利用特征嵌入来计算距离并检测 OOD 样本。与参数化密度估计方法相比，KNN 的优势在于它不施加强烈的分布假设，并且对于拥有数十亿图像的大型数据库非常高效。所提出的 AdaODD 通过显式地利用被检测为 OOD 的在线测试样本来改进 KNN [13]。AdaODD 的完整细节在算法 1 中给出。对于给定的测试样本 $x_o$，我们首先在记忆库 $M$ 中寻找其 $k$ 个最近邻，该记忆库由归一化的训练特征初始化，并且所有 ID 样本的尺度 $s_i$ 都设置为 $1$。然后，我们将得分 $S(x_o)$ 计算为 $k$ 个最近邻的平均加权距离的负数 $\frac{1}{k} \sum_{i=1}^{k} -||z_o - z_{(i)}|| * s_{(i)}$。选择阈值 $\lambda$ 以使得很大一部分 ID 验证数据（95%）能够被正确分类。AdaODD 的核心组件是算法 1 中的`记忆扩增`，具体细节解释如下。

![1778137873919](C:\Users\TanLinJi\AppData\Roaming\Typora\typora-user-images\1778137873919.png)

​		(1) `OOD 样本选择与 ID 样本选择`：使用所有在线样本来扩增 $M$ 是不可取的，因为它们会向记忆库中添加噪声并可能降低性能。为了避免这个问题，我们使用一个选择边距 $\gamma \ge 1$ 来过滤不可靠的 OOD 样本。只有当 $x$ 的得分小于 $\gamma\lambda$ 时，它才是一个被可靠检测出的 OOD 样本。同样，只有当得分高于 $\lambda/\gamma$ 时，它才是一个可靠的 ID 样本。(为什么这样设置)

​		(2) `凸显被检测出的 OOD 样本的贡献`：回顾一下，我们的目标是为 OOD 样本分配比 ID 样本更小的分数。然而，给定 $x_o \in D^{out}$，如果其 $k$ 个最近邻都是 OOD 样本，它们将高度相似，并且 $-||z_o - z_i||$ 将会很大（在绝对值上很小），这与我们的目标相反。因此，我们为可靠检测出的 OOD 样本引入了一个较大的尺度 $\kappa \ge 1$，以凸显它们的贡献。（我们使用一个示例来说明 **OOD尺度 (OOD scale)** $\kappa$ 的重要性。假设 $\lambda = -1.0$ 且 $k = 1$。给定 $x_o = [2, 2] \in \mathcal{D}^{out}$ 并且 $\mathcal{M} = \{([1, 1], 1), ([0, 0], 1)\}$，我们将得到 $S(x_o) = -1.4$。如果 $\mathcal{M}$ 包含一个 OOD 样本 $([2.5, 2.5], \kappa)$，我们希望具有 OOD 邻居的 $x_o$ 获得一个较低的分数。在这种情况下，得分为 $-0.707\kappa$。如果 $\kappa = 1$，那么 $S(x_o)$ 反而会从 $-1.4$ 增加到 $-0.7$，并且由于 OOD 邻居的存在，它将被错误地识别为 ID 样本。因此，我们需要一个大于 1 的尺度来纠正这种现象。$\kappa \rightarrow \infty$ 意味着一旦 $x_o$ 的 $k$ 个最近邻中包含 OOD 样本，那么 $x_o$ 就将被识别为 OOD。）

​		(3) `非参数自适应`：在选择了可靠检测出的 OOD 样本并为它们分配了适当的尺度之后，我们通过包含选定的特征向量来扩增记忆库，即 $M = M \bigcup (z_o, \kappa)$。相比之下，现有的 TTA 方法 [14], [15], [18], [19] 需要额外的训练或微调才能将来自被检测 OOD 样本的信息添加到模型中，这导致了更多的计算开销，并使它们不太适合在线环境。

#### C. Discussion of the Proposed Setting and Method

​		`与使用辅助OOD数据的OOD检测的区别` 这一系列工作在训练期间对模型进行正则化。例如，鼓励模型为分布外数据赋予更高的能量 [7], [20], [21], [22]，或对分布外数据点给出具有**均匀分布 (uniform distribution)** 的预测 [11], [23]。最近，VOS [24] 尝试合成异常值以减轻对**辅助OOD数据 (auxiliary OOD data)** 的需求。然而，真实的测试/OOD分布可能与辅助/合成的OOD数据相差任意远。与它们相比，我们的工作试图在推理期间直接利用在线的OOD实例，而不是在训练期间，并且在很大程度上超越了所有现有的研究。

​		`现有的TTA方法能否直接用于OOD检测任务？` (i) 大多数现有的**在线学习 (online learning)** 或 TTA 方法主要是为图像分类任务设计的。相比之下，我们的论文解决的是OOD检测问题，其中训练数据的标签空间与测试OOD数据不同。这种根本差异使得 OOD 检测任务本质上比**领域泛化 (domain generalization)** 或传统的在线学习更具挑战性。(ii) 由于训练和测试目标之间的差异，现有的用于图像分类的 TTA 方法不容易扩展到 OOD 检测任务。OOD 检测需要区分已知和未知的类别，并且在训练期间缺乏 OOD 样本使得它比传统的图像分类任务更复杂。(iii) 大多数 TTA 或在线学习方法通常需要调整模型参数，我们在实验中确实设计并比较了各种简单的在线学习基线。然而，OOD 样本在现实世界的场景中通常是稀缺的，这会导致在线学习期间出现不稳定的梯度。因此，与传统的离线训练相比，在 OOD 检测中实现稳定有效的在线学习变得更具挑战性。这就是为什么我们提出的 AdaODD 方法（该方法利用测试时样本来适应决策边界）相比依赖于基于梯度的微调方法展现出优势的原因。

### 3 Theoretical Justification

#### A. Log Conditional Densities Score Function

​		为了研究OOD样本如何影响检测过程，我们将得分函数划分为两个组件，一个仅依赖于ID近邻，另一个依赖于所选的测试近邻。在下文中，我们将所选样本视为**低置信度 (low-confidence, LC)** ID样本，而来自原始ID分布的样本则是**高置信度 (high-confidence, HC)** ID样本。因为我们没有测试样本的真实标签，所以LC ID样本集将同时包含ID和OOD样本。3 我们证明，与以前使用HC ID近邻和固定边界的方法不同，AdaODD通过来自LC样本信息的得分来调整边界，并倾向于更低的假阳性率。在无法访问OOD分布的情况下，典型的决策规则是
$$
I\{S(x|D_{HC} ) \ge \lambda\}, \tag1
$$
其中 $D_{HC}$ 是原始ID样本集。我们将得分高于 $\lambda$ 的样本视为ID。潜在的缺点是 $\lambda$ 的值通常相对较小，以便分布内检测保持足够的准确率。如果我们能够访问估计的LC ID信息，我们可以使用如下的组合决策规则：
$$
I\{S(x|D_{HC} , \hat{D}_{LC} ) \ge \lambda\}, \tag2
$$
其中 $\hat{D}_{LC}$ 是测试期间的低置信度ID样本集。直观地讲，人们通常希望得分函数表现出与ID概率函数相似的行为，即，得分越高意味着测试样本 $x$ 来自ID的机会/概率越大。因此，理想的选择之一是将得分函数设置为与对数概率成正比，即
$$
S(x|D_{HC} , \hat{D}_{LC} ) \propto \log P(x \text{ from ID}|D_{HC} , \hat{D}_{LC} ).
$$
我们通过**最大似然估计器 (maximum likelihood estimator)** 分析得到以下等式，
$$
S(x|D_{HC} , \hat{D}_{LC} ) \propto \underbrace{\sum_{x_i \in D_{HC}} \log p_{hc}(x|x_i)}_{(a)} + \underbrace{\sum_{x_j \in \hat{D}_{LC}} \log p_{lc}(x|x_j)}_{(b)}, \tag3
$$
其中 $p_{hc}(\cdot)$ 和 $p_{lc}(\cdot)$ 分别是给定来自HC样本集的参考样本和测试期间收集的LC样本集的参考样本时，ID的条件密度/质量函数。

#### B. Nonparametric Density Estimator

​		到目前为止，如何估计 (3) 中的局部密度 (local density)和 LC ID 样本集仍不清楚。在本小节中，我们应用 KNN 来近似局部密度 [25] 并推导我们的决策规则。在 III-B1 节中，我们展示了如何估计 LC ID 样本集。为了便于讨论，我们首先考虑一个人工设定，即我们知道测试样本真实的内/外分布标签，并且每个样本都通过其 $l_2$ 范数 ($l_2$ norm)**进行归一化，以将表示投影到单位球面上。对于给定的测试样本 $x$，我们首先使用**余弦相似度 (cosine similarity)从 $D_{in} \cup D_{test}$ 中收集距离 $x$ 最近的 $k$ 个样本作为 $D_{KNN}(x)$，其中 $D_{test}$ 是服从 ID/OOD 某种混合分布的测试时样本集。不失一般性，我们假设 $D_{KNN}(x)$ 分别包含来自 HC/LC ID 的 $k_1$ 和 $k_2$ 个样本。我们将 $D_{KNN}(x)$ 中包含 HC ID/LC ID 样本的两个不相交的数据集记为 $D_{KNN}^{hc}(x)$ 和 $D_{KNN}^{lc}(x)$。接下来，我们对条件密度 $p_{hc}(x|x_i)$ 和 $p_{lc}(x|x_j)$ 做出如下假设：假设 1：存在两个正常数 $\lambda_{hc} < \lambda_{lc}$，使得 $p_{hc}(x|x_i)$ 和 $p_{lc}(x|x_j)$ 分别与 $\exp(-\lambda_{hc}||x - x_i||^2)$ 和 $\exp(-\lambda_{lc}||x - x_j||^2)$ 成正比。(在这里，我们假设**密度函数 (density function)** 的尾部表现为指数形式。通过更复杂的分析，我们可以进一步将密度的限制放宽为次高斯 (subgaussian)/次指数 (subexponential) 分布。)

​		我们使用 $\lambda_{hc}$ 和 $\lambda_{lc}$ 来描述 HC ID 和 LC ID 样本的影响。让我们考虑一个样本 $x$ 和一个靠近 $x$ 的参考点 $y$。直观地讲，如果 $y$ 是一个 HC ID 样本，人们可能会期望 $x$ 是 ID 样本的概率更高；如果 $y$ 被认为是来自 LC ID 样本，那么其概率就会更低。换句话说，对于相同的参考样本 $y$，我们应该有 $p_{hc}(x|y) > p_{lc}(x|y)$，这可以通过在假设 1 中设置 $\lambda_{hc} < \lambda_{lc}$ 来实现。在测试阶段，我们很难确保 $y$ 来自 ID 还是 OOD 分布。因此，在评估样本 $x$ 为 ID 的概率时，将 $y$ 视为一个比正常 ID 参考样本贡献更小的参考样本会更安全。(如果在测试阶段可以获得确切的 OOD 样本集，那么 OOD 检测任务就落入了**半监督学习 (semi-supervised learning)** 领域，我们可以使用**对数似然比 (log-likelihood-ratio)** [26] 作为得分函数，即

$$S(x|D_{in}, \hat{D}_{out}) \propto \log(P(x \text{ from ID}|D_{in})/P(x \text{ from OOD}|D_{out}))$$,我们在 B 节中详细说明了实证结果和比较。) 然后，我们将假设 1 与 $D_{KNN}^{hc}(x)$ 和 $D_{KNN}^{lc}(x)$ 结合，以替代项 (a) 和 (b) 中的 $D_{hc}$ 和 $\hat{D}_{lc}$。

$$(a) \propto - \sum_{x_i \in D_{KNN}^{hc}(x)} \lambda_{hc}||x - x_i||^2; \quad (b) \propto - \sum_{x_i \in D_{KNN}^{lc}(x)} \lambda_{lc}||x - x_i||^2$$

$$\Rightarrow (a) + (b) \propto - \sum_{x_i \in D_{KNN}(x)} ||x - x_i||^2 \cdot s_i$$

其中，如果 $x_j$ 来自 HC ID，我们设置 $s_j = 1$，否则 $s_j = \lambda_{lc}/\lambda_{hc}$。最后，将上述推导与 (3) 结合，我们最终得到了算法 1 第 7 行中使用的决策规则：
$$
I \left\{ - \sum_{x_j \in D_{KNN}} ||x - x_j||^2 \cdot s_j \ge \lambda \right\} \tag4
$$
请注意，在检测规则 (4) 中，我们需要了解 $D_{KNN}$ 中所有样本的分布标签，而这在实践中对于来自 $D_{test}$ 的样本是不可获取的。在本文中，我们转而提出一种通过具有稍微大一点的 $\lambda$ 的 (4) 来估计分布标签的方法。由于通常 ID 样本数量 $N$ 远大于测试样本数量 $n$，检测额外的 ID 样本只能带来边际提升。我们可以直接使用 $D_{in}$ 来代替所有 ID 样本。

​		我们使用图1中的两种场景来展示决策规则 $(4)$ 的合理性。图2中良好分离的ID/OOD。在此场景中，当 $(4)$ 中的 $(a)$ 足够大时（即，$x$ 处于HC ID分布的**高密度区域 (high-density regime)**），$x$ 处的LC ID分布密度必定非常小，那么 $\log p_{lc} \approx 0$。在这种情况下，决策规则退化为经典的检测规则 $(1)$。另一方面，当 $x$ 来自LC ID分布时，预期 $(a)$ 和 $(b)$ 都很小（较大的 $\lambda_{lc}$ 降低了 $p_{lc}$ 的贡献），我们可以安全地分配OOD标签，同时牺牲极小的ID准确率。

`图2`  $D^{out} = N (10, 1/2)$

​		`图1中重叠的ID/OOD。`在这里，我们考虑某些高密度区域中的ID/OOD重叠。经典的OOD检测规则 $(1)$ 具有较小的阈值 $\lambda$，可能导致大量OOD样本被分类为ID样本。当应用检测规则 $(4)$ 时，我们测量给定HC ID/LC ID样本集的**条件密度 (conditional density)**。只要 $(a)$ 或 $(b)$ 项中有一个足够小，这对应于 $x$ 远离HC ID参考样本或具有足够近的估计LC ID参考样本的情况，我们仍然可以为样本 $x$ 分配OOD标签。因此，我们的方法产生了更低的假阳性率。

​		1) OOD样本集的估计：接下来，我们考虑OOD样本集的估计。令 $D_{KNN}^{lc,T}$ 和 $D_{KNN}^{lc,F}$ 表示 $D_{KNN}^{lc}$ 中分别包含真实OOD样本和错误OOD样本的不相交样本集。我们将有如下的分离：
$$
-\sum_{x_j \in D_{KNN}} s(x_j)||x - x_j||^2 = - \sum_{x_j \in D_{KNN}^{lc,T}(x)} s(x_j)||x - x_j||^2 - \sum_{x_j \in D_{KNN}^{lc,F}(x)} s(x_j)||x - x_j||^2. \tag5
$$
如果我们略微高估了OOD样本的大小，相应的 $\sum_{x_j \in D_{KNN}^{lc}(x)} ||x - x_j||^2 s(x_j)$ 将被高估，并在ID/OOD检测上产生较低的**曲线下面积 (Area Under Curve, AUC)**。另一方面，如果我们只收集具有足够置信度的LC ID样本（例如，得分函数中足够小的值），相应的 $\sum_{x_j \in D_{KNN}^{lc}(x)} ||x - x_j||^2 s(x_j)$ 变小，并且 $(4)$ 的决策规则更倾向于高置信度ID样本。在极端情况下，$D_{KNN}^{lc}(x)$ 为空集，$\sum_{x_j \in D_{KNN}^{lc}(x)} ||x - x_j||^2 s(x_j)$ 变为0，检测规则 $(4)$ 退化为经典的检测规则 $(1)$。因此，仅仅保留具有高置信度的测试样本作为检测到的OOD样本是更安全的。在本文中，我们提出在测试阶段使用以下决策规则来收集估计的OOD样本（算法1第9行）：
$$
I \left\{ S(x_0|D_{KNN}^{hc}(x), \hat{D}_{KNN}^{lc}(x)) < \lambda \cdot \gamma \right\}, \tag6
$$
其中 $\gamma \ge 1$，且 $\hat{D}_{KNN}^{lc}(x)$ 是估计的OOD样本集，在开始时为空。

#### C. Benefits of Our Model-Free Framework

​		首先，传统的基于模型的技术（如 Energy [7] 和 SSD+ [27]）通常依赖于特定的训练目标，这就需要显式地在 ID 和 OOD 实例之间制造差距。相反，我们的方法在模型架构上提供了灵活性，包括兼容**卷积神经网络 (CNNs)**，以及更近期的基于 Transformer 的 ViT 模型。此外，它适应各种训练过程，并且兼容在多种损失函数（例如交叉熵损失或对比损失）下训练的模型。这种多功能性突显了我们的方法在不同学习范式中的适应性。其次，在测试时自适应的背景下，传统方法通常需要修改模型参数 [14], [28]，这带来了**知识遗忘 (knowledge forgetting)** 的风险，并可能对性能产生不利影响。相比之下，我们的方法避免了对模型本身进行直接修改。取而代之的是，它无缝地融入了从测试过程中收集的额外知识，在不牺牲效率的前提下提升了灵活性。

### 术语

`false positive rate，FPR` 假阳性率，在所有实际为“阴性（负类）”的样本中，被模型错误地判定为“阳性（正类）”的比例（在本文中，指那些原本应该被系统拦截的 OOD 样本，却被模型错误地当作了安全、可信的 ID 样本（分布内样本）而予以“放行”的比例。）。计算公式

$$FPR = \frac{FP}{FP + TN}$$

- FP (False Positive, 假阳性/误报)：实际是阴性，但被系统错判为阳性。
- TN (True Negative, 真阴性)：实际是阴性，系统也正确地判为阴性。
- 分母 ($FP + TN$)：也就是所有实际为阴性的样本总数。

FPR95，当模型调整其阈值，以确保能正确识别出 95% 的分布内 (ID) 样本时，此时系统对 OOD 样本的假阳性率是多少。数值越低越好





`如何区分分布外样本和分布内样本，这两类样本分别代表什么？`

这是一个非常核心的问题！理解了这两个概念以及它们的区分方式，就等于掌握了这篇论文的“世界观”。

我为你详细拆解本文对这两类样本的定义，以及作者是如何通过具体的算法将它们区分开的。

1. 这两类样本分别代表什么含义？

- **分布内样本 (In-Distribution, 简称 ID)**：
  - **含义**：指那些与模型**训练集数据服从相同分布**的数据 。在论文的设定中，这些数据属于模型预先学习过的类别集合 $\mathcal{Y}=\{1,2,...,c\}$ 。  
  - **系统的处理方式**：对于 ID 输入，系统的工作是放行，并**预测它们真实的类别** 。  
- **分布外样本 (Out-of-Distribution, 简称 OOD)**：
  - **含义**：指在测试阶段出现的、来自与训练集完全不同分布 $\mathcal{D}^{out}$ 的数据 。本文假设 OOD 样本的标签空间与 ID 样本是不重合的（这在学术上称为标签偏移，Label Shift）。  
  - **系统的处理方式**：对于 OOD 输入，由于模型从未见过这类数据，强行分类会导致极其荒谬的结果。因此系统的正确做法是**直接拒绝它们，不作任何预测** 。  

2. 本文是如何区分它们的？(核心方法 AdaODD)

传统的做法是静态设定一个界限。但这篇论文提出了一种动态的、无需训练参数的判别方法，全称叫**非参数测试时自适应框架 (AdaODD)** 。  

系统区分一个新来的测试样本 $x_o$ 到底属于 ID 还是 OOD，主要分为以下几个核心步骤：

- **第一步：构建特征记忆库 (Memory Bank)** 首先，提取所有 ID 训练数据的特征（并进行 L2 归一化），存入一个记忆库 $\mathcal{M}$ 中 。此时库里全是“自己人”，它们的基础权重（尺度 $s_i$）都设为 1 。  

- **第二步：寻找近邻并打分** 当一个未知的测试样本 $x_o$ 到来时，提取它的特征 $z_o$，然后在记忆库中寻找与它距离最近的 $k$ 个邻居（KNN） 。 接着，计算一个得分 $S(x_o)$。得分的公式是这 $k$ 个近邻的加权距离平均值的负数：   

  $$S(x_o)=\frac{1}{k}\sum_{i=1}^{k}-||z_{o}-z_{(i)}||s_{(i)}$$

   *逻辑在于：如果新样本离记忆库里的邻居越近（距离越小），前面加上负号后，这个得分就越大，说明它越有可能是 ID 样本。*  

- **第三步：阈值判定 (Thresholding)** 系统预设了一个阈值 $\lambda$（通常选取能让 95% 的 ID 验证集数据正确分类的值） 。  

  - 如果得分 **$S(x_o) \ge \lambda$**：判定为 **ID 样本**，放行 。  
  - 如果得分 **$S(x_o) < \lambda$**：判定为 **OOD 样本**，拒绝 。  

- **第四步：动态自适应（本文的最大创新点）** 为了应对分布重叠导致漏报的问题，AdaODD 会把测试流中**置信度很高**的检测结果重新加回记忆库中 ：  

  - 如果判定为极可能是 OOD（得分低于 $\lambda\gamma$），系统会将该样本加入记忆库，并赋予一个**极大的权重 $\kappa$**（例如 $\kappa=10$） 。这就相当于在雷区插了一个巨大且显眼的警示牌，以后再有相似的 OOD 样本靠近它，得分会被这个巨大的权重瞬间拉低，从而更准确地被拦截 。  

通过这种方式，模型不仅能在一开始进行基础的区分，还能像免疫系统一样，在遇到新型病毒（OOD样本）后记住它们，从而在接下来的测试中越来越准。



`什么是服从相同分布的数据？`

如果两批数据是由同一个“底层规则”或者同一个“数据源”按完全相同的概率规律产生的，我们就说它们“服从相同分布”。这意味着这两批数据在整体的统计特征上（比如平均值、方差、各类别的比例、数据的范围等）是高度一致的。





`''我们假设来自Din样本的标签与Dout的标签互不重叠''，'ID 和 OOD 分布显著重叠' 这两句话怎么理解?`

这两句话其实点出了 OOD（分布外）检测任务中最核心的“理想与现实的矛盾”。我们把这两句话拆开来，用大白话和生活中的例子来理解：

1. 假设来自 OOD 样本的标签与 ID 的标签互不重叠

- **通俗解释**：这讲的是“客观事实”。ID（分布内，即训练过的）和 OOD（分布外，即没见过的）在类别上必须是泾渭分明的，井水不犯河水。
- **举个例子**：假设你的模型在训练时（ID 数据）只学过分辨“猫”、“狗”、“兔子”（标签空间 $\mathcal{Y}_{ID} = \{猫, 狗, 兔子\}$）。那么在测试时，来的 OOD 样本必须是模型绝对没学过的东西，比如“汽车”、“飞机”、“水杯”。
- **为什么要有这个假设？** 如果 OOD 样本是一只长得很奇怪的“无毛猫”，那它依然属于“猫”这个标签，这就属于“难样本（Hard Example）”，而不是 OOD。OOD 检测的前提就是：**来的必须是全新的、不在已知字典里的类别。**

2. ID 和 OOD 分布显著重叠

- **通俗解释**：这讲的是“模型的错觉”**。这里的“分布”通常指的是模型提取出来的**特征空间（Feature Space）分布。虽然客观上它们不是一类东西（标签不重叠），但在模型的眼里，它们的特征长得太像了，混在了一起。
- **举个例子**：ID 数据里有一只“趴在草地上的黄狗”，OOD 数据里来了一辆“停在草地上的黄色挖掘机”。虽然一个是动物一个是车（标签互不重叠），但它们都有大面积的黄色、都有草地背景、边缘轮廓可能在某几个卷积层里产生了相似的激活。结果就是，模型把这个挖掘机提取成一个特征向量后，发现它和黄狗的特征向量在多维空间里离得非常近——这就是**分布显著重叠**。

把两句话连起来看：这就是为什么需要 AdaODD

这两句话合在一起，构成了一个巨大的技术挑战：

**“它们明明是完全不同的东西（标签不重叠），但在模型的特征空间里却挤在了一起（分布重叠）。”**

- **传统方法的死局**：由于训练时没见过挖掘机，模型只能根据“狗”的特征画一个固定的圈（静态边界）。但因为挖掘机的特征刚好落在了这个圈的边缘甚至圈内（分布重叠），固定边界就会失效，把挖掘机误判成狗（**导致极高的假阳性率 FPR**）。
- **本文 AdaODD 的破局之道**：既然一开始画的静态死边界分不开它们，那我就在测试的时候，利用这些新来的 OOD 样本（在线测试数据），动态地把边界收紧。只要我认准了几个距离极远的 OOD 样本，给它们赋予很大的权重（大尺度 $\kappa$），我就能把原来那个死板的圈给挤压变形，从而精准地把混在 ID 边缘的 OOD 给剔除出去。





**1. 为什么 OOD 的收录条件是 $S(x_o) < \lambda\gamma$ ？**

- 假设 $\lambda = -1.0$, $\gamma = 2$。那么 $\lambda\gamma = -2.0$。
- 条件变成了：**得分必须小于 -2.0**（比原本的判定线 -1.0 还要低得多）。
- **物理意义**：它不仅得是 OOD，还得是“离 ID 极度遥远、非常确信的 OOD”。只有满足这种严苛条件的“高质量异常样本”，才有资格被放进错题本，并且被赋予 $\kappa$ 的大权重。这有效防止了把长得像正常样本的异常样本放进去捣乱。

**2. 为什么 ID 的收录条件是 $S(x_o) > \lambda/\gamma$ ？**

- 同样假设 $\lambda = -1.0$, $\gamma = 2$。那么 $\lambda/\gamma = -0.5$。
- 条件变成了：**得分必须大于 -0.5**（比原本的判定线 -1.0 还要高得多，更接近 0）。
- **物理意义**：它不仅得是 ID，还得是“深深扎堆在 ID 核心区域、极其纯正的 ID”。只有这种样本才会被收录进去扩充正常数据的特征丰度。



**Selection margin ($\gamma$) 的作用是“宁缺毋滥”**。在测试时，我们会遇到很多长得模棱两可的样本。如果我们把所有预测为 OOD 的样本全塞进记忆库，一旦混进去一个其实是正常的样本（假阳性），记忆库就被污染了。$\gamma$ 就是用来设定一个“安全缓冲区”，只有得分极其极端、模型**百分之百确信**的样本，才准进入记忆库。

**Sample scale ($\kappa$) 的作用是“以一当十”**。在线测试时，遇到真实 OOD 样本的概率通常很低。为了让这零星几个 OOD 样本发挥出强大的“排斥力”，算法给它们赋予了一个极大的乘数权重 $\kappa$。当未来的测试样本靠近这个 OOD 样本时，算出来的距离会被 $\kappa$ 放大十几倍甚至几十倍，从而瞬间拉低得分，确保它被判定为异常。



`为什么要做L2归一化？`

L2 归一化的目的是**消除特征“绝对大小（幅度）”的干扰，只保留“方向（语义）”差异**。
把特征向量除以它的 L2 范数（$||h_\theta(x_o)||_2$），在几何上相当于把所有样本的特征点强制投影到了一个半径为 1 的超球面上。这样一来，计算两个样本的距离时，就纯粹是在比较它们在特征空间中的“夹角”（代表它们包含的语义信息是否相似），而不会受图像亮度、对比度等无关因素的影响，使得 KNN 的距离度量极其稳定。



`计算 OOD 得分时，距离为什么要添加负号？`
这是为了**对齐常识逻辑：得分越高越代表是正常样本（ID），得分越低越代表是异常样本（OOD）**。

两点之间的距离（$||z_o - z_{(i)}||$）永远是一个正数。如果距离越小，说明它和记忆库里的正常样本越像。给距离加上负号后，很小的距离（比如 0.1）变成了高分（-0.1），很大的距离（比如 5.0）变成了极低分（-5.0）。这样就可以统一用 $S(x_o) \ge \lambda$ 来判断是否为 ID 了。
