# Transferable 3D Adversarial Shape Completion using Diffusion Models

## Abstract

​		近期将**几何特征**和 **Transformer** 融入 **3D 点云特征学习**的研究，显著提高了 **3D 深度学习模型**的性能 。然而，它们针对**对抗攻击**的**鲁棒性**尚未得到彻底探索 。现有的攻击方法主要集中在**白盒**场景，且难以**迁移**到最近提出的 **3D 深度学习模型**上 。更糟糕的是，这些攻击向 3D 坐标引入**扰动**，生成了不真实的**对抗样本**，导致在对抗 **3D 对抗防御**时表现不佳 。在本文中，我们利用**扩散模型**生成高质量的**对抗点云** 。通过使用部分点作为**先验知识**，我们通过带有**对抗引导**的**形状补全**来生成逼真的**对抗样本** 。所提出的**对抗形状补全**允许更可靠地生成对抗点云 。为了增强**攻击迁移性**，我们深入研究了 **3D 点云**的特性，并通过对点云进行**随机下采样**，利用**模型不确定性**来更好地推断模型分类 。我们采用**集成对抗引导**，以提高跨不同网络架构的**迁移性** 。为了保持生成质量，我们通过计算**显著性分数**，将**对抗引导**仅限制在点云的**关键点**上 。大量的实验表明，我们提出的攻击在对抗**黑盒模型**和防御方面均优于**最先进的**对抗攻击方法 。我们的**黑盒攻击**为评估各种 **3D 点云分类模型**的**鲁棒性**建立了一个新的**基准**。

## 6 Discussion

​		实验表明，在 $\ell_{inf} = 0.16$ 的约束下，当前的攻击方法在针对**黑盒模型**时表现不佳，特别是在椅子、飞机和汽车类别中 。然而，由于**长尾分布**的训练数据集，这些黑盒模型对提出的 3DAdvDiff 极其脆弱 。因此，我们提倡针对 3D 点云模型采用一种更均衡的训练方法，并创建规模与2DImageNet 相似的大规模数据集 。尽管 3DAdvDiff 提供了令人满意的攻击性能，但其主要弱点在于需要提高时间效率以确保更好的**泛化能力** 。

## 7 Conclusion

​		在本文中，我们介绍了首个旨在对近期开发的 **3D 点云分类模型**执行**黑盒对抗攻击**的方法 。我们的研究也是将**扩散模型**用于 **3D 对抗攻击**的开创性工作 。具体而言，我们通过 **3D 对抗形状补全**生成**对抗样本**，确保了可靠且高质量的**点云生成** 。我们提出了几种策略来增强所提出攻击的**迁移性**，包括利用**模型不确定性**来改进预测推断，通过来自各种**替代模型**的**集成 Logits** 增强**对抗引导**，以及通过**关键点选择**来提高生成质量 。在鲁棒数据集上进行的全面实验验证了我们所提出攻击的有效性 。我们的方法为 **黑盒 3D 对抗攻击**的未来发展建立了一个坚实的**基准** 。

## 术语

`Ensemble Logits` 集成Logits, Logits 指的是深度学习模型在 Softmax 层之前的原始输出数值。集成 Logits 是指将多个不同模型（替代模型）输出的 Logits 值进行加权或平均，以此作为攻击的综合引导信号。

​		**通俗理解**：就像你想骗过一群考官，只听一个人的喜好（单一模型）可能不够，于是你同时听取好几个模拟考官（替代模型）的打分意见（Logits），综合起来调整你的答案，这样骗过真正考官的概率就更大了。



`Adversarial Guidance` 对抗引导，在生成模型的生成过程中（如扩散模型的去噪步），人为加入一个引导信号（通常基于目标模型的梯度），使得最终生成的结果具有攻击性。

​		*通俗理解*：在画画（生成点云）的过程中，旁边有个人（对抗引导）一直悄悄指挥：“往这边画一点，让这个椅子看起来像飞机”，最终画出来的东西虽然还像椅子，但机器会把它认成飞机。
