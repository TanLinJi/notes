# Adapting Point Cloud Analysis via Multimodal Bayesian Distribution Learning

### Abstract

​		大型多模态3D视觉-语言模型在多种3D任务中展现出强大的泛化能力，但在域偏移下，其性能仍然会显著下降。这推动了近期关于**测试时自适应** (Test-Time Adaptation, TTA) 的研究，该技术允许模型使用测试期数据进行在线自适应。在现有的 TTA 方法中，基于缓存的机制被广泛采用，以利用先前观察到的样本来进行在线预测细化。然而，它们仅存储有限的历史信息，导致随着测试流的演进而产生渐进式的信息丢失。此外，它们的预测对数 (logits) 是启发式融合的，使得自适应过程不稳定。为了解决这些局限性，我们提出了 `BayesMM`，这是一种用于测试时**点云** (Point Cloud) 分析的多模态贝叶斯分布学习框架。BayesMM 将每个类别的文本先验和流式视觉特征建模为**高斯分布** (Gaussian distributions)：文本参数源自语义提示，而视觉参数则随着到达的样本在线更新。这两种模态通过贝叶斯模型平均进行融合，该方法基于后验证据自动调整它们的贡献度，从而产生一个统一的预测，该预测无需训练即可不断适应演变的测试期数据。在多个点云基准测试上的广泛实验表明，BayesMM 在分布偏移下保持了鲁棒性，平均提升超过 4%。

### 1 Introduction

​		激光雷达 (LiDAR) 和 RGB-D 相机等3D传感器 [6, 9] 因其可靠的几何感知能力 [17, 28]，已成为机器人和自动驾驶的基础，推动了场景重建、目标识别和空间理解的进步。在此基础之上，近期涌现了利用大规模`点-图-文`三元组进行对比预训练的大型多模态3D模型 [23, 38, 39]。它们在共享的嵌入空间内对齐几何与文本表示，从而实现开放词汇的**点云** (Point Cloud) 识别和强大的**零样本泛化** (Zero-shot Generalization) [16, 48, 51, 53]，由此展示了多模态学习在可扩展和可泛化3D感知方面的潜力 [4, 29, 33, 35]。

​		尽管大型多模态3D模型取得了显著进展，但当面临训练和测试分布之间的**域偏移** (Domain Shifts) 时，其性能通常会下降。因此，近期的研究探索了**测试时自适应** (Test-Time Adaptation, TTA) [2, 3, 7, 14, 24, 26, 43, 52]，使模型能够使用无标签的测试数据动态地细化预测，而无需重新训练。在这些方法中，基于缓存的方法通过维护一个包含高置信度测试样本的紧凑记忆库来进行在线模型调整，展现出了特别的前景。然而，其有限的缓存容量会导致渐进式的信息丢失，无法捕捉长期的分布统计数据，如图1顶部所示。随着测试流的演进，连续的样本替换进一步放大了这一问题，导致自适应过程不稳定，甚至引发**灾难性遗忘** (Catastrophic Forgetting)。此外，基于缓存的预测对数与零样本预测对数 (logits) 之间的启发式融合依赖于凭经验调整的超参数 [14, 24, 46]，这使得自适应过程在跨域时变得不稳定。这些局限性阻碍了基于缓存的方法在现实世界场景中的实用性。

​		为了解决上述局限性，我们提出了 BayesMM，这是一种用于自适应点云识别的免训练动态贝叶斯分布学习框架。如图1底部所示，BayesMM 在一个统一的概率表述下联合建模文本和几何模态。具体而言，它假设每个类别的特征在两种模态中均服从**高斯分布** (Gaussian distributions)。文本分布首先从语义提示中推导得出，提供捕捉跨提示变体语义多样性的类别先验（class-wise priors）；而几何分布则根据测试流进行渐进式细化，以反映视觉变化。贝叶斯公式允许模型自动调整模态权重，从而产生一个统一的预测分布，确保自适应过程的稳定性和一致性。

​		为了量化 BayesMM 实现的多模态一致性，我们测量了沿着自适应轨迹学习到的多模态分布与其真实参考之间的 Kullback-Leibler (KL) 散度 [12] 和**最大均值差异** (Maximum Mean Discrepancy, MMD) [27] 。如图2右侧所示，完整的贝叶斯融合获得了比单模态消融低得多的 KL 和 MMD 值，表明文本和几何表示之间实现了更连贯的对齐 。随着自适应过程的进行，这两个指标都在稳步下降，这表明 BayesMM 持续优化了联合特征空间，而不是过拟合于短期样本 。具体而言，在初始和后期阶段 ($t_1$–$t_4$) 之间，平均 KL 散度从 17.2 降至 12.6，MMD 从 0.91 降至 0.71，这证明我们的贝叶斯融合随着时间的推移有效地稳定了特征动态并增强了跨模态分布一致性 。

主要贡献总结如下 ：

- 我们提出了 BayesMM，这是一种免训练的动态贝叶斯分布学习框架，用于测试时的自适应点云识别 。
- 我们构建了一个统一的概率模型，通过动态参数更新和贝叶斯融合来联合建模几何和文本模态，以实现跨模态对齐 。
- 我们在多个基准测试上进行了广泛的实验，证明 BayesMM 在各种 3D 场景中实现了鲁棒且一致的测试时自适应性能 。

### 2 Related work

​		`大型多模态3D模型的测试时自适应` TTA [10, 14, 52] 旨在通过在推理期间使用测试数据调整模型表示来解决分布偏移问题，而无需访问源数据。在 3D 领域，近期的工作如 MATE [18]、BFTT3D [30] 和 CloudFixer [22] 探索了通过**掩码自编码** (Masked Auto-encoding)、**原型记忆** (Prototype Memory) 和基于扩散的恢复来进行点云识别的自适应策略。然而，这些方法依赖于源域数据，使得它们不太适合 TTA。大型多模态3D模型 [15, 40, 44, 50] 的出现使得可泛化和开放词汇的 3D 理解成为可能。代表性模型（如 ULIP-2 [39]、OpenShape [16] 和 Uni3D [48]）通过**对比对齐** (Contrastive Alignment) [1] 在大规模点-图-文三元组上进行联合预训练，从而统一了几何与语义表示以实现零样本泛化。基于这些基础模型，近期通过基于缓存的机制探索了大型多模态 3D 模型中的 TTA [14, 19, 24, 34, 36, 45]。这些方法维护了一个在推理期间收集的特征表示缓存，并检索相关条目来指导预测更新，从而实现高效的在线自适应。相比之下，我们的 BayesMM 将测试时自适应表述为动态多模态分布学习。它不断地建模几何分布，并通过**贝叶斯推断** (Bayesian Inference) 将它们与文本先验相结合，其中模态权重在贝叶斯原则下自动调整，从而在分布偏移下实现鲁棒的点云识别。

​		`分布学习` **分布学习** (Distribution Learning) 通过利用特征空间的统计结构而非依赖固定的表示，为自适应识别模型提供了一个原则性的框架。经典方法如**高斯判别分析** (Gaussian Discriminant Analysis) [11, 31, 51] 假设每个类别的特征服从高斯分布，并以闭式解的形式构建概率分类器。近期的进展将这一思想扩展到了测试时场景。DOTA [10] 将视觉-语言模型的测试时自适应表述为从测试数据流中对高斯参数进行在线估计，以捕获非平稳偏移。在线高斯测试时自适应 [8, 42] 进一步在推理期间更新类别级别的均值和协方差，从而在无需外部记忆的情况下实现持续自适应。更近期的研究中，ADAPT [47] 通过调整逐类统计量，将服从高斯分布的测试特征与类别原型对齐，而 BCA [49] 则利用不断到来的样本增量式地细化高斯参数，以实现高效且稳定的**无源自适应** (Source-free Adaptation)。与这些基于单模态高斯的方法不同，BayesMM 通过联合估计几何与文本分布，并通过贝叶斯推断将它们整合，从而执行多模态分布学习，以实现鲁棒的点云识别。

### 5 Conclusion

​		这项工作提出了 BayesMM，这是一种**免训练** (Training-free) 的动态**贝叶斯分布学习** (Bayesian Distribution Learning) 框架，用于在分布偏移下进行自适应的点云识别。通过将几何和文本模态建模为高斯分布，并通过**贝叶斯模型平均** (Bayesian model averaging) 将它们整合，BayesMM 在无需额外训练或辅助网络的情况下，实现了稳定且**感知不确定性** (Uncertainty-aware) 的自适应。在受损的、跨域的以及大规模的基准测试上进行的广泛实验表明，与现有的基于缓存和测试时自适应的方法相比，BayesMM 显著提高了鲁棒性、稳定性以及跨模态泛化能力。总而言之，BayesMM 为多模态测试时自适应确立了一个原则性且高效的范式，以期在动态环境中实现可靠的 3D 理解。
